## Already in place (do not change)

- `src/i18n/index.ts`: `t(key, vars?)` with `{name}` placeholders, `tn(baseKey, n, vars?)` for plurals
  (`baseKey.one` / `baseKey.other`, `{n}` is the count), `locale()` → `'it-IT' | 'en-GB'`, `getLang()`.
- `src/i18n/it.ts` / `en.ts` merge one fragment per area: `src/i18n/it/<area>.ts` (plain object) and
  `src/i18n/en/<area>.ts` (typed `Record<keyof typeof it, string>`, so a missing English key is a type error).
- Language switch remounts the Shell, so calling `t()` during render is enough (no hook needed).
- `labels.ts` (plugin vocabulary), `overview.ts` `relativeTime`, the Settings language selector: done.

## Your job

1. In **your files only**, replace every user-visible Italian string (JSX text, `title`, `aria-label`,
   `placeholder`, toasts, thrown `Error` messages shown to the person, confirm texts) with `t('<area>.<name>')`.
   Keys: `<area>.<view>.<short-name>` in lowerCamel, e.g. `lavori.board.empty`. Template strings with
   values → placeholders: `` `ultimo uso ${x}` `` → `t('esplora.progetti.lastUse', { when: x })`.
   Counts that change the noun → `tn`.
2. Put the Italian text **verbatim** (same punctuation, same typographic apostrophes) in
   `src/i18n/it/<area>.ts` and a natural, concise English translation in `src/i18n/en/<area>.ts`.
   English style: sentence case, plain verbs, no title case, same tone. Section names:
   Projects, For you, Work, Decisions, Handoff, Health, Search, Graph, Settings, Getting started.
3. Hard-coded `'it-IT'` in `toLocale…` / `Intl` → `locale()`.
4. Do **not** translate: text written into wiki files (log entries, `closed by …; not proven:`,
   `human:<id>`, table cells, frontmatter), plugin command names (`/wiki-sync`), file paths, code
   identifiers, values compared in logic (e.g. `IndexState` literals used as keys — translate only where displayed).
5. Imports: in `src/lib/*` and `src/state/*` use `import { t } from '../i18n/index.ts';` (node tests need the
   extension); in views/components `'../i18n'` is fine. If a local variable named `t` shadows the import
   (e.g. `THEMES.map((t) => …)`), rename the local.
6. Do not edit `src/i18n/it.ts`, `src/i18n/en.ts`, other areas' fragments or files outside your list.
   Do not commit. Do not run `npm install`.
